# 09 Integración UI y Temas

# 🎨 Prompts de Motor de Temas y Experiencia Interactiva

Este directorio contiene las instrucciones para implementar la lógica de personalización visual (Tailwind) y el calendario de reservas en el cliente.

---

## 📋 Lista de Prompts (Ejecución Secuencial)

1.  **[01. Motor de Temas Dinámicos](./01-dynamic-theme-engine.md)**: 
    - Inyección de variables CSS (`--primary`, `--logo`) desde el JSONB.
    - Extension de Tailwind CSS para soporte dinámico.
2.  **[02. Calendario de Reserva (Next.js)](./02-booking-calendar-client.md)**: 
    - Implementación del selector de slots de 1h en el Front Office.
    - Validación de disponibilidad en tiempo real.

---

> [!IMPORTANT]
> **Elegancia**: El diseño final debe ser limpio y moderno. Utiliza la inyección de temas para permitir que cualquier negocio luzca profesional sin importar su paleta de colores.
