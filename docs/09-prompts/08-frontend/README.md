# 08 Frontend Base

# 🌐 Prompts de Inicialización del Frontend (Admin & Client)

Este directorio contiene las instrucciones para configurar el esqueleto funcional del las aplicaciones de usuario dentro del monorepo **CGBG**.

---

## 📋 Lista de Prompts (Ejecución Secuencial)

1.  **[01. Dashboard Admin (Angular + Tailwind)](./01-angular-admin-setup.md)**: 
    - Inicialización de la panel administrativo con Angular v17+.
    - Configuración de **Tailwind CSS** para una estética premium.
    - Estructura de `Core`, `Shared` y `Features`.
2.  **[02. Front Office (Next.js + Tailwind)](./02-nextjs-client-setup.md)**: 
    - Configuracion del sitio público de reservas con **Next.js (App Router)**.
    - Setup del inyector de temas dinámicos.

---

> [!IMPORTANT]
> **Diseño Unificado**: Ambas aplicaciones deben compartir el sistema de diseño basado en Tailwind CSS para asegurar una experiencia de usuario coherente en todo el ecosistema.
