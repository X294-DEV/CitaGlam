# 07 Dashboards y Admin Global

# 📊 Prompts de Analítica y Gestión Maestral del SaaS

Este directorio contiene las instrucciones para implementar las herramientas de reporte y control global del ecosistema **CGBG** dentro de `docs/07-codigo/cgbg-webapp/`.

---

## 📋 Lista de Prompts (Ejecución Secuencial)

1.  **[01. Centro de Control SuperAdmin](./01-superadmin-control-center.md)**: 
    - CRUD de configuraciones globales (Modo Mantenimiento, Banners).
    - Gestión de paquetes de suscripicón y monitoreo de Tenants.
2.  **[02. Analítica del Tenant](./02-tenant-analytics-endpoints.md)**: 
    - Métricas de ingresos por citas completadas.
    - Reporte de **Top Clientes** para programas de fidelidad.
3.  **[03. Lógica de Mantenimiento](./03-saas-maintenance-logic.md)**: 
    - Guardia global para bloquear el acceso al sistema.
    - Excepciones para el rol administrador.

---

> [!IMPORTANT]
> **Fidelización**: El reporte de "Top Clientes" es una base estratégica para futuras campañas de marketing y ofertas personalizadas que el Tenant podrá lanzar desde su panel.
